# Price Tracker

Парсер цен: собирает каталог с [books.toscrape.com](https://books.toscrape.com) (учебный сайт для тренировки парсинга), сохраняет в Excel и показывает, у каких товаров цена изменилась с прошлого запуска.

## Что получается

Файл `prices.xlsx` с двумя листами:

- **Цены**: название, цена, наличие, ссылка.
- **Изменения цен**: товары, у которых цена отличается от прошлого запуска (было, стало, разница).

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python main.py --pages 3
```

Параметры: `--pages` (сколько страниц каталога, по 20 книг, по умолчанию 3), `--output` (имя файла, по умолчанию `prices.xlsx`).

Чтобы отслеживать изменения, запускай парсер регулярно: цены прошлого запуска хранятся в `history.json`.

## Как устроено

- `scraper.py`: загрузка страниц (requests) и разбор HTML (BeautifulSoup). Пауза 1 с между запросами.
- `report.py`: Excel (openpyxl) и сравнение с историей.
- `main.py`: командная строка.
- `test_tracker.py`: тесты на готовом HTML, без обращения к сайту. Запуск: `python -m unittest`.

## Под другой сайт

Менять нужно `parse_page` в `scraper.py` (селекторы карточки товара) и адрес страниц. Перед парсингом реального сайта проверяй его `robots.txt` и условия использования.
